# Student Course Management System

This is a web-based Student Course Management System developed using Python and Django. It helps manage students, courses, instructors, enrollments, marks, and course materials.

## Running the server

To run the server, execute the following command:

```bash
python manage.py runserver
```

The server will start on port 8080. You can access it by navigating to `http://127.0.0.1:8000/myapp/home/` in your web browser.
